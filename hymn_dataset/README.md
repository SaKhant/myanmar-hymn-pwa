# Recovered Myanmar Hymns data

This folder was extracted from the supplied desktop app and normalized for reuse.

Files:
- myanmar_hymns.json — Myanmar main hymns
- english_hymns.json — English main hymns
- myanmar_yp.json — Myanmar YP songs
- english_yp.json — English YP songs
- categories.json — Myanmar category pages mapped to hymn numbers
- hymn_library.csv — lightweight unified review/import table
- summary.json — extraction counts and validation summary

Each JSON hymn record preserves page headings, metadata, cross references, audio URL (when present), structured verse/chorus sections, and a plain lyrics_text field.
