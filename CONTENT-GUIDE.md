# Content Guide — where everything lives

Use this map whenever you want to **add or edit** songs. After any change run
`npm run build` to confirm nothing is broken, then push to deploy.

---

## HYMNS

### Lyrics

| Content | File(s) | Hand-editable? |
|---|---|---|
| Myanmar hymns (incl. 675–686) | `hymn_dataset/myanmar_hymns.json` | YES — plain JSON |
| English hymns | `hymn_dataset/english_hymns.json` | YES |
| Matu hymns | `hymn_dataset/matu_hymns.json` | YES — plain JSON |
| Kachin hymns | `hymn_dataset/kachin_hymns.json` | YES — plain JSON |

**How to fix one lyric line (Myanmar/English):** open the JSON, search for the
hymn's `"number"`, find the text inside `"sections"` → `"lines"`, edit that one
line. Do not reword anything else.

### Myanmar hymn extras

| Content | Where | How it works |
|---|---|---|
| Guitar chords | `lib/hymns/guitar/arrangements/001.ts` … `110.ts`, registered in `lib/hymns/guitar-data.ts` | One file per hymn number. Only arrangements marked `"reviewed"` appear in the app. |
| Piano sheet | `app/api/piano-score/1/route.ts` | Fetched live from hymnal.net, never bundled. Currently wired for hymn 1 only. |
| Number notes (Jianpu) | `public/jianpu/myanmar-hymn-1.png` | One PNG per hymn. Readers show it automatically for hymn 1 via `numberedNotesImageSrc`. Add more PNGs here using the name pattern. |

## YP SONGS

| Content | File(s) | Notes |
|---|---|---|
| Myanmar YP lyrics | `hymn_dataset/myanmar_yp.json` + batch files in `hymn_dataset/yp-batches/` | Batches are merged into the main list at load time |
| English YP lyrics | `hymn_dataset/english_yp.json` + batches | Same merge |
| Guitar chords (Myanmar + English) | No local files — computed on demand | Server parses chord images from hymnal.net in `app/api/yp-guitar/[id]/route.ts` |

**Important:** a YP song only gets guitar/audio if its real hymnal.net source is
listed in `lib/hymns/yp-sources.ts` → `VERIFIED_YP_SOURCES`. Never guess an
entry — match by English title first.

## QUICK RECIPES

**Fix a wrong word in a Myanmar hymn** → `hymn_dataset/myanmar_hymns.json`

**Add guitar chords for hymn N** → create/update `lib/hymns/guitar/arrangements/NNN.ts`,
then make sure it is imported AND set to `"status": "reviewed"` in `guitar-data.ts`.

**Add Jianpu for hymn N** → save `public/jianpu/myanmar-hymn-N.png`, then wire
it where the reader sets `numberedNotesImageSrc`.

**Add new YP songs (next batch)** → type them into a new
`hymn_dataset/yp-batches/myanmar_yp_XXX_YYY.json`, import it in
`lib/hymns/data.ts`, and verify audio mapping in `yp-sources.ts`.

**Before big data changes:** copy the old file into `hymn_dataset/backups/`
first. Never translate or invent missing Myanmar lines — check the physical songbook.
